Lapisan Virtualisasi & Jaringan Privat: WSL2 + Hyper-V + Tailscale Mesh

Zero-Trust HIPAA/UU PDP Ready

Karena Windows Win32 tidak mendukung kompilasi native kernel CUDA Triton/FlashAttention tingkat lanjut, inference engine performa tinggi (SGLang dan vLLM) dijalankan di dalam WSL2 (Ubuntu 22.04 LTS) dengan akselerasi GPU langsung melalui arsitektur Hyper-V Virtual Switch. Seluruh komunikasi data inferensi dihubungkan melalui Tailscale Mesh VPN (IP 100.x.y.z) yang terenkripsi WireGuard point-to-point tanpa membuka port publik:

1. Hyper-V GPU Passthrough

Driver NVIDIA Windows otomatis meneruskan akselerasi CUDA ke kernel WSL2 dengan latensi komputasi mendekati bare-metal (<1% overhead).

2. Tailscale WireGuard Mesh

Memberikan IP privat statis (misal 100.64.0.15) sehingga backend FastAPI di host Windows atau puskesmas cabang dapat mengakses API LLM secara privat.

3. Zero-Exposure Security

Tidak ada port 0.0.0.0:8000 atau 30000 yang terbuka ke internet publik. Seluruh prompt klinis terlindungi dari penyadapan jaringan publik.

PLAN A: SGLang Engine Port Default: 30000

RadixAttention: Optimasi Dialog Multi-Turn Klinis

Sangat ideal untuk skenario percakapan psikologi PsychoBot. Algoritma RadixAttention mengorganisasikan KV-cache ke dalam struktur data Radix Tree. System prompt klinis (~400 token) dan riwayat turn sebelumnya di-cache secara persisten di VRAM GPU.

• Keunggulan Utama:
Meniadakan kalkulasi ulang KV-cache hingga 80% pada Turn 2 s.d Turn 10, memangkas TTFT dari 850ms ke <120ms.
Perintah Eksekusi di WSL2: 
python3 -m sglang.launch_server \
  --model-path Qwen/Qwen2.5-1.5B-Instruct \
  --port 30000 --host 0.0.0.0
Konfigurasi SIAGA: LLM_PROVIDER=sglang Endpoint: /v1/chat/completions
PLAN B: vLLM Engine Port Default: 8000

PagedAttention: Throughput Konkurensi Masif Tanpa Fragmentasi

Sangat ideal saat jam sibuk konsultasi faskes di mana puluhan pasien dan konselor mengakses sistem secara simultan. Algoritma PagedAttention membagi memori KV-cache ke dalam blok halaman virtual non-contiguous mirip paging pada OS kernel.

• Keunggulan Utama:
Meniadakan pemborosan memori KV-cache hingga 96% akibat fragmentasi internal, menaikkan kapasitas konkurensi throughput 4x tanpa galat OOM.
Perintah Eksekusi di WSL2: 
python3 -m vllm.entrypoints.openai.api_server \
  --model Qwen/Qwen2.5-1.5B-Instruct \
  --port 8000 --host 0.0.0.0 \
  --gpu-memory-utilization 0.9
Konfigurasi SIAGA: LLM_PROVIDER=vllm Endpoint: /v1/chat/completions

5. Engine L3 Cumulative Intent Momentum (CIM) & Simulator Stateful

Mekanisme pertahanan stateful multi-turn untuk melacak eskalasi niat koersif (Crescendo Attack) dan memicu intervensi Canary Probe secara deterministik.

Formulasi Akumulasi Momentum Stateful (CIM Engine):
$$M_N = \text{clamp}\left(\gamma_N \cdot M_{N-1} + w_1 \cdot \Delta_N \cdot \text{Arah}_N + w_2 \cdot \text{Anchor}_N \cdot \text{Arah}_N + w_3 \cdot r_N, \; 0, \; 1\right)$$

Formulasi Cumulative Intent Momentum (CIM) melacak akselerasi niat koersif antar turn percakapan secara stateful, mengeliminasi kelemahan stateless guardrail konvensional.

1. Delta Risiko ($\Delta_N$) Akselerasi
$$\Delta_N = r_N - r_{N-1}$$

Perubahan derajat risiko turn saat ini dibandingkan turn sebelumnya.

2. Konsistensi Arah ($\text{Arah}_N$) Sliding K=3
$$\text{Arah}_N = \frac{1}{K} \sum_{i=0}^{K-1} \mathbb{I}(\Delta_{N-i} > 0)$$

Proporsi turn eskalatif dalam jendela $K=3$. Jika acak, $\text{Arah}_N \approx 0$ membatalkan momentum.

3. Jangkar Semantik ($\text{Anchor}_N$) Eksploitasi
$$\text{Anchor}_N = \max\left(0, \cos(v(U_N), v(S_{N-1})) - \text{Base}\right)$$

Mendeteksi penyerang yang mengeksploitasi respons sistem $S_{N-1}$ untuk perangkap berikutnya.

4. Peluruhan Adaptif ($\gamma_N$) Resurgence
$$\gamma_N = \exp\left(-\lambda \cdot \text{Dist}(v_N, v_{\text{harm}})\right)$$

Topik normal meluruhkan momentum, tetapi lantai $\gamma_{\text{floor}} = 0.75$ mencegah manipulasi reset memori.

5. Skor Fusi Keputusan Akhir ($\text{Score}$) Multi-Layer Fusion
$$\text{Score} = 0.65 \cdot M_N + 0.25 \cdot \text{Intent}_{L1} + 0.10 \cdot \text{Risk}_{L2}$$

Kombinasi berbobot antara momentum stateful L3, intent classifier ONNX L1, dan validasi wewenang klinis L2.
